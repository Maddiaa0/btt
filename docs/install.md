# Install btt

Use the installer generated by cargo-dist and attached to each
[GitHub release](https://github.com/Maddiaa0/btt/releases).
It downloads a prebuilt binary for Linux or macOS on x64 or ARM64.
No Rust toolchain, package manager, or compilation is required.
The binaries include WASM grammar support.

## Install the latest release

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/Maddiaa0/btt/releases/latest/download/btt-cli-installer.sh | sh
btt --version
```

The installer writes to `$CARGO_HOME/bin`, or `~/.cargo/bin` when
`CARGO_HOME` is unset, and configures your shell's PATH. Restart your shell
if the current session cannot find `btt`. Rust does not need to be installed
for this directory to work.

Run the same command again to update to the latest release.

The generated installer checks the archive against an embedded SHA-256
checksum when `sha256sum` is available. It prints a message and skips that
check when the command is missing, including on a stock macOS installation.
The GitHub Action requires checksum verification on both platforms.

## Pin a release

Replace `latest/download` with `download/<tag>` to select an exact version:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/Maddiaa0/btt/releases/download/v0.2.0/btt-cli-installer.sh | sh
```

Use a release that satisfies your project's dependency-age policy. The
`latest` URL does not enforce a minimum age.

To inspect the script before executing it, download it separately:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/Maddiaa0/btt/releases/download/v0.2.0/btt-cli-installer.sh -o btt-installer.sh
less btt-installer.sh
sh btt-installer.sh
```

## Choose a directory without changing shell configuration

Set `BTT_CLI_UNMANAGED_INSTALL` on the `sh` process. This installs directly
into the specified directory and disables shell configuration changes:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/Maddiaa0/btt/releases/download/v0.2.0/btt-cli-installer.sh | BTT_CLI_UNMANAGED_INSTALL="$HOME/.local/bin" sh
export PATH="$HOME/.local/bin:$PATH"
btt --version
```

For the default install directory without shell configuration changes,
use `BTT_CLI_NO_MODIFY_PATH=1` on the `sh` process instead.

## Use GitHub Actions

The [btt action](https://github.com/Maddiaa0/btt-action) installs a prebuilt
binary, verifies its checksum, adds it to PATH, and runs `btt check`:

```yaml
steps:
  - uses: actions/checkout@v4.2.2
  - uses: Maddiaa0/btt-action@v1
    with:
      version: '0.2.0'
```

Pin the action to a full commit SHA when your workflow requires immutable
references. Use `install-only: 'true'` to run your own later steps, or
`test-command` to execute your project's tests after the tree check passes.

Other CI systems can use the pinned installer with an unmanaged directory
and add that directory to PATH using their runner's environment mechanism.
